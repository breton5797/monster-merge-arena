# Monster Merge Arena — 게임 디자인 문서 (시제품)

수치는 전부 `src/data/*.json`이 기준이다. 이 문서와 JSON이 다르면 JSON이 맞다.

## 1. 한 판의 흐름 (3분)
```
스테이지 선택 → 시작 몬스터 3마리 지급 → 전투 시작(3:00 카운트다운)
  ├ 적 처치 → 에너지 획득 → [소환] 버튼으로 무작위 기본 몬스터 소환
  ├ 몬스터 드래그 → 다른 몬스터 위에 놓으면 합성
  ├ 20초마다 일시정지 → 3택 선택 (총 8회)
  └ 기지 HP 0 → 패배 / 3:00 생존(+스테이지3은 보스 처치) → 승리
→ 결과 화면: 생존 시간, 처치 수, 이번 판 신규 발견, [다시하기] [도감]
```

## 2. 화면 구성 (세로 720×1280)
| 영역 | 위치 | 내용 |
|---|---|---|
| 상단 바 | 0~120 | 남은 시간, 기지 HP 바, 일시정지 |
| 전장 | 120~820 | 4개 레인, 적이 위에서 아래로 내려옴 |
| 보드 | 820~1080 | 4열 × 2행 = 8칸. 위 행 = 앞줄, 아래 행 = 뒷줄 |
| 하단 바 | 1080~1280 | 에너지, [소환] 버튼(비용 표시), 도감 신규 알림 |

## 3. 전투 규칙
- 보드의 각 열 = 레인 1개. 몬스터는 **자기 레인의 적만** 공격한다.
- `melee`(근접): 앞줄에서만 공격 가능, 사거리 = 보드 바로 위 120px. 뒷줄에 두면 공격 안 함(합성 대기용).
- `ranged`(원거리): 앞·뒷줄 어디서든 자기 레인 전체를 공격.
- 적이 보드 앞(경계선)에 닿으면 멈춰서 **그 레인 앞줄 몬스터**를 공격한다. 앞줄이 비어 있으면 통과해 기지에 데미지.
- 몬스터 HP 0 → 사망이 아니라 **기절 10초**, 50% HP로 복귀 (캐주얼 피로도 완화). 기절 중에도 합성 재료로 쓸 수 있다.
- 비행 적(`flying`)은 앞줄을 무시하고 기지로 직행 → 원거리 몬스터만 맞출 수 있다.
- 공격 대상: 자기 레인에서 기지에 가장 가까운 적.

### 상성 (elements.json)
5속성 순환: **불 → 풀 → 바위 → 번개 → 물 → 불** (화살표 방향이 유리)
- 유리: 데미지 ×1.5 / 불리: ×0.75 / 그 외: ×1.0

## 4. 합성 규칙 (핵심)
드래그한 몬스터 A를 몬스터 B 위에 놓으면 아래 순서로 판정한다. `MergeSystem.resolve(a, b)`는 순수 함수.

| 순서 | 조건 | 결과 |
|---|---|---|
| 1 | A와 B가 같은 종, 같은 ★ (★3 미만) | ★+1 (스탯 ×1.6). 결과는 B 자리 |
| 2 | 둘 다 기본 몬스터(tier 1)이고 `fusions.json`에 레시피 존재 (순서 무관) | 해당 합성 몬스터 ★1. 도감 기록 |
| 3 | 둘 다 기본 몬스터이고 레시피 없음 | **키메라** ★1 (약하지만 실패 위로용. 기본 몬스터 2마리보다 살짝 강함) |
| 4 | 그 외 (tier 2끼리 다른 종, 키메라 포함, ★ 다름) | 합성 불가 → 원위치로 튕김 + 흔들림 |

- **★ 보존**: 레시피 합성 결과의 ★ = 두 재료 ★ 평균 내림. (★2 + ★2 → 합성 몬스터 ★2) → 같은 종 강화 후 합성하는 전략 허용
- 합성 결과는 HP 100%로 생성, 기절 상태 해제
- **밸런스 원칙**: 레시피 몬스터 ★1 ≈ 기본 몬스터 ★2보다 강해야 한다. 그래야 "같은 거 합치기"보다 "새 조합 실험"이 이득이다.

### 발견 연출
- 처음 만드는 레시피: 0.6초 슬로모션 + 화면 중앙 컷인("NEW! 증기정령") + 도감 알림 점
- 이미 발견한 레시피: 짧은 이펙트만
- 키메라 첫 생성: "실패…?" 컷인 + "이 조합은 레시피가 없습니다" 토스트 (실패도 정보)

## 5. 소환 & 에너지
- 적 처치 시 에너지 획득 (enemies.json `energy`)
- 소환 비용: 시작 10, 소환할 때마다 +5 (config.json)
- 소환 결과: 기본 몬스터 10종 중 무작위, 빈칸 중 앞줄 우선 배치. 빈칸 없으면 버튼 비활성

## 6. 3택 시스템 (PickSystem)
20초마다 BattleScene을 일시정지하고 카드 3장을 보여준다. 카드 종류(config.json `pick.weights`):
| 카드 | 효과 |
|---|---|
| 몬스터 | 특정 기본 몬스터 1마리 지급 (빈칸 필요, 없으면 이 카드는 제외) |
| 몬스터 2마리 | 같은 기본 몬스터 2마리 (빈칸 2개 필요) |
| 레시피 힌트 | 미발견 레시피 1개의 재료 중 하나를 공개 + 그 몬스터 지급 |
| 강화 | 특정 속성 공격력 +20% (판 동안) |
| 치유 | 기지 HP +25%, 기절 몬스터 즉시 복귀 |
| 에너지 | 에너지 +15 |

**보정 규칙** (실력·전략 개입 + 발견 유도):
- 3장 중 최소 1장은 "보드의 몬스터와 합치면 **미발견** 레시피가 되는" 몬스터 카드 (가능할 때)
- 같은 카드 종류 3장 금지
- 무료 리롤 1회/판 (Post-MVP에서 보상형 광고 리롤 추가)

| 이벤트 | 속성 |

| `pick_shown` | options[] |

시제품 저장: localStorage 큐 + `?debug=1`일 때 화면에 이벤트 로그 패널. 결과 화면에 [로그 복사] 버튼(플레이테스터가 붙여넣기로 제출).

## 10. 도감 (CodexScene)
- 5열 그리드: 기본 10 → 합성 15 → 키메라 1
- 발견: 컬러 + 이름 + 레시피(재료 2개 아이콘) + 스킬 설명
- 미발견: 검은 실루엣 + 속성 색 테두리(힌트) + "??? + ???"
- 3택의 "레시피 힌트"로 재료 하나가 공개되면 "불꼬리 + ???"로 표시
- 상단: 발견 수 `7 / 26`, 완성 시 보상 연출(Post-MVP: 꾸미기 해금)
