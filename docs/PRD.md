# Monster Merge Arena PRD
> 작성일: 2026-10-24 | 버전: v1.0 | 상태: 시제품 기획

## 1. 프로젝트 개요 & 비전
- **한 줄 설명**: 3분 동안 몬스터를 합성해 강력한 팀을 만들고, 몰려오는 적을 물리치는 게임.
- **풀고자 하는 문제**: 머지 게임은 대부분 "같은 것 2개 → 다음 단계"로 결과가 뻔해 금방 지루해진다. 자동전투 게임은 판이 길어 짧은 틈새 시간에 하기 어렵다.
- **솔루션**: 서로 다른 몬스터를 합치면 예상 못 한 능력의 몬스터가 나오는 **발견형 합성** + **3분 단판**.
- **비전**: 시즌마다 기본 몬스터·레시피를 추가하는 "합성 도감 수집" 게임으로 운영. 숏폼에서 "이거 합치면 뭐 나옴?" 콘텐츠가 자연 확산되는 구조.

## 2. 타겟 사용자 & 페르소나
- **1차**: 출퇴근·쉬는 시간에 5분 내 한 판을 원하는 20~30대 모바일 캐주얼 유저 (운빨존많겜, 랜덤다이스, 머지 게임 경험자). 불만: 판이 길거나, 결과가 운에만 좌우됨.
- **2차**: 도감 채우기·조합 탐구를 좋아하는 10대 후반~20대 (포켓몬, 리틀 알케미류 선호). 숏폼에서 조합 공략을 찾아보는 유형.
- **안티 페르소나**: 깊은 PvP 경쟁, 장시간 성장 노가다, 정교한 컨트롤 액션을 원하는 하드코어 유저.

## 3. 핵심 기능 목록
### MVP (시제품)
| 기능 | 설명 | 우선순위 |
|------|------|---------|
| 3분 전투 | 레인형 자동 전투, 기지 HP 0이면 패배, 3분 버티고 보스 처치 시 승리 | 🔴 필수 |
| 드래그 합성 | 같은 종=★강화 / 레시피=신규 몬스터 / 그 외=키메라 | 🔴 필수 |
| 라운드 3택 | 20초마다 일시정지, 몬스터·강화 아이템 중 3개 제시 | 🔴 필수 |
| 몬스터 데이터 | 기본 10종, 합성 15종, 키메라 1종 | 🔴 필수 |
| 도감 | 발견 기록, 미발견 실루엣 + 속성 힌트, 발견 연출 | 🔴 필수 |
| 스테이지 | 3개 + 보스 1종 | 🔴 필수 |
| 분석 이벤트 | 검증 지표 수집 | 🔴 필수 |
| 손맛 연출 | 합성 이펙트, 신규 발견 컷인, 화면 흔들림, 사운드 | 🟡 중요 |
| 일일 도전 | 고정 시드 판 | 🟢 선택 |

### Post-MVP
- 3단계 합성(합성 몬스터끼리 합성), 기본 몬스터 확장(시즌제)
- 꾸미기(몬스터 스킨, 기지 테마), 광고 제거 상품, 보상형 광고(부활·리롤)
- 주간 랭킹, 친구 조합 공유 카드(숏폼 공유용 이미지 자동 생성)
- Steam 완전판: 엔드리스 모드, 커스텀 규칙, 업적

## 4. 기술 스택
| 레이어 | 기술 | 선택 이유 |
|--------|------|---------|
| 게임 엔진 | Phaser 3.90 + TypeScript + Vite | 기존 운영작(타이니 가디언즈)과 동일 → 코드·노하우 재사용, Claude Code 생산성 높음 |
| 데이터 | JSON (몬스터·레시피·스테이지) | 밸런스 수정에 코드 수정 불필요, 시즌 추가 쉬움 |
| 저장 | localStorage → 출시 시 Capacitor Preferences | 시제품은 서버 불필요 |
| 테스트 | Vitest | 합성·상성 규칙 회귀 방지 |
| 시제품 배포 | Vercel 또는 itch.io 웹 빌드 | 링크 하나로 플레이테스트 |
| 모바일 | Capacitor (Android → iOS) | 웹 코드 그대로 스토어 빌드 |
| 광고/결제 | AdMob, 스토어 인앱결제 (출시 단계) | 시제품에서는 스텁 |
| Steam | Electron 또는 Tauri + Steamworks (검토) | 모바일 검증 후 결정 |
| 아트 | 플레이스홀더 → mflux 로컬 생성 스프라이트 | 재미 검증 전 아트 비용 0 |

## 5. 개발 로드맵 & 마일스톤
| 단계 | 기간 | 주요 산출물 |
|------|------|-----------|
| Phase 1 — 시제품 | 1~2주 | 웹 빌드, 핵심 루프 전부, 분석 이벤트 |
| Phase 1.5 — 검증 | 1주 | 플레이테스트 20~50명, 숏폼 테스트 영상 3~5개, 지표 판정 |
| Phase 2 — 출시 준비 | 2주 | 아트 교체, 몬스터 확장(기본 14 / 합성 30 목표), 광고·결제, Capacitor 빌드 |
| Phase 3 — 출시·운영 | 이후 월 1회 | Google Play 출시 → iOS, 월 1회 레시피 시즌 업데이트, Steam 검토 |

월 1개 신작 목표에 맞춰, 검증에서 기준 미달이면 Phase 2로 가지 않고 다음 후보로 넘어간다(§8 판정 기준).

## 6. 수익 모델
- **모바일**: 무료. 보상형 광고(부활 1회, 3택 리롤), 전면광고는 판 종료 후 3판에 1회 이하. 광고 제거 상품, 꾸미기(스킨·기지 테마).
- **Steam**: 유료 완전판(광고 없음, 엔드리스·커스텀 모드 포함) 별도 검토. 두 플랫폼에서 같은 과금 구조를 강제하지 않는다.
- **목표**: 시제품 단계에서는 매출 목표를 두지 않는다. 출시 후 3개월 데이터(광고 eCPM, DAU)로 월 목표를 정한다. 무리한 숫자를 미리 가정하지 않는다.

## 7. 경쟁사 분석
| 경쟁 장르/게임 | 강점 | 약점 | 우리의 차별점 |
|--------|------|------|------------|
| 운빨존많겜 / 랜덤다이스류 | 짧은 판, 운+전략 | 합성 결과가 예측 가능 | 다른 종 합성 시 결과가 미지 → 발견의 재미 |
| 머지 퍼즐(머지 드래곤즈류) | 수집·정리 만족감 | 느리고 전투 긴장감 없음 | 3분 전투 압박 속에서 합성 판단 |
| 뱀파이어 서바이버류 | 짧은 생존, 빌드 선택 | 조작 피로, 몬스터 수집 요소 없음 | 조작은 드래그 합성뿐, 도감 수집 |
| 리틀 알케미류 | 조합 발견 | 게임성(도전·승패) 없음 | 발견한 조합이 바로 전투력이 됨 |

> Phase 1.5 전에 틱톡·유튜브 쇼츠의 "머지 + 자동전투" 최신 흥행작을 따로 조사해 차별점을 재점검한다.

## 8. 성공 지표 (KPI) — 시제품 검증 기준
| 지표 | 통과 기준 | 의미 |
|------|---------|------|
| 세션당 판 수 | 평균 3판 이상 | "한 판 더" 욕구 |
| 레시피 발견률 | 첫 세션에서 평균 4개 이상 발견 | 발견 루프가 작동 |
| 도감 진입률 | 플레이어의 50% 이상이 도감을 1회 이상 열어봄 | 수집 동기 |
| D1 재방문 | 30% 이상 (웹 테스트 기준) | 반복 플레이 |
| 정성 피드백 | "다른 조합 해보고 싶다" 류 응답 다수 | 핵심 질문 답 |

**판정**: 5개 중 3개 이상 통과 → Phase 2 진행 / 미달 → 합성 결과의 놀라움(능력 차이)을 키워 1회 재테스트, 그래도 미달이면 보류.
